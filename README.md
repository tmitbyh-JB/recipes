# Recipes

A personal collection of tested, home-cooked recipes.

**Live site:** https://tmitbyh-JB.github.io/recipes/

## Structure
- `index.html` — landing page (recipe list is in the `RECIPES` array near the bottom)
- `recipes/` — one HTML page per recipe, built from `Recipe_Template.html`
- `images/` — photos, named to match the recipe file (e.g. `banana-bread.jpg`)

## Adding a recipe
1. Copy the recipe template into `recipes/` and fill it in.
2. Add a photo to `images/` (optional).
3. Add an entry to the `RECIPES` array in `index.html`.
